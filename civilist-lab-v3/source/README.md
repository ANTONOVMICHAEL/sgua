# ЦИВИЛИСТ / Правовая лаборатория

Авторский экран-атлас для конкурсного семинарского занятия «Государство на равных?» по теме «Публично-правовые образования как субъекты гражданского права». Автор: Антонов М. А., кафедра гражданского права СГЮА.

Проект рассчитан на один ноутбук и проектор. Студенты заранее решают три казуса по выданному домашнему заданию и обсуждают новые обстоятельства в аудитории. Веб-приложение не принимает ответы, не создает учетные записи и не обращается к серверу.

## Запуск и сборка

Требуется Node.js 24 или совместимая версия, npm.

```bash
npm ci
npm run dev
npm run build
```

`dist/` содержит версию для GitHub Pages с базовым путем `/sgua/civilist-lab-v3/`, локальными шрифтами и ресурсами, `sw.js` для кеширования и `offline.html` как автономный единый файл. Откройте автономный файл из локальной папки после скачивания; весь код, шрифты и логотип встроены внутрь.

Исходный юридический ключ преподавателя хранится отдельно от каталога `dist` и не должен публиковаться вместе с сайтом. В публичной части есть только общие выводы, вызываемые вручную на последних шагах дел.

## Управление

- `1`, `2`, `3` в библиотеке открывают соответствующий том.
- `Пробел` или `→` открывает следующий материал, `←` возвращает предыдущий.
- `Esc` возвращает в библиотеку; открытие тома продолжает с последнего шага.
- Нижняя шкала дает прямой переход к нужному шагу. Ни один материал не переключается сам.
- Кнопка в правом верхнем углу включает полноэкранный режим.

Для проведения пары см. [инструкцию преподавателя](INSTRUCTOR_GUIDE.md). Проверенные нормы и редакторские оговорки находятся в [юридической сверке](docs/LEGAL_AUDIT.md).

## Структура

`src/cases.js` содержит содержание трех дел и итоговой карты. `src/main.js` управляет экраном и локальным прогрессом. `src/books3d.js` строит три объемных тома на Three.js и отдельный Canvas 2D при отсутствии WebGL. `src/style.css` задает экранную типографику и адаптацию. `scripts/package.mjs` собирает автономную копию и манифест кеша.
