# Проверка цифрового атласа

Дата: 7 ноября 2026 года. Проверялся проект v3 для GitHub Pages. Статус отдельных пунктов приведен без приравнивания сборки к браузерной проверке.

## Подтверждено

- Vite собрал статический сайт и автономный HTML без ошибок. `node --check` прошел для трех модулей JavaScript. Версии зависимостей закреплены в lockfile.
- В браузере Work открыт локальный preview. Проверены библиотека, фабулы, карточки, правовые выводы и итоговая карта; явные переходы мышью и клавишами `1/2/3`, `Пробел`, `Esc` работают. Ускоренный проход последовательно открыл все 16 сцен и итоговую карту за 16 нажатий «далее».
- Возврат к библиотеке сохраняет этап дела; перезагрузка страницы восстановила последнее открытое дело и сцену. Прямой выбор этапа и обратный ход работают.
- Проверены карточки 1А и 3В, выводы I-III, итоговая карта. Переполнение в выводах II и III устранено сокращением экранного текста; полный анализ оставлен в отдельном ключе. В ходе прохода найден и исправлен переход, который ранее перескакивал к сохраненному последнему шагу следующего дела.
- Облачный браузер Work не создает WebGL-контекст. Запасной Canvas 2D с тремя книгами отрисован; клик по томам I и III открывает соответствующие дела. Видимый текстовый список остается доступным независимо от графики.
- Автономный HTML собран как один файл. Проверка статического содержимого не обнаружила внешних или корневых ссылок на ресурсы; шрифты и логотип встроены. Service worker предварительно кеширует файлы опубликованной версии при успешной установке.
- Юридические формулировки трех дел сверены с нормами и разъяснениями, приведенными в `docs/LEGAL_AUDIT.md`; вымышленные документы помечены как учебные модели.

## Границы проверки

- Аппаратный WebGL в облачном браузере отключен. Объемная Three.js-сцена реализована, но ее визуальное поведение в этой среде нельзя подтвердить. Запасной вид проверен.
- Облачный браузер заблокировал открытие локального `file://` по политике URL. Поэтому автономный файл не испытан в браузере с физически отключенной сетью; проверены его сборка и отсутствие внешних ссылок. Не считать это прохождением офлайн-теста.
- В доступном браузере нельзя задать точные размеры окна 1920×1080, 1366×768, 2560×1440 и мобильный размер. Проведен визуальный осмотр текущего окна около 1363×930; остальные размеры следует считать неподтвержденными до отдельной браузерной проверки.
- Полноэкранный запрос отклонен политикой облачного браузера (`TypeError: not granted`). Кнопка вызывает стандартный Fullscreen API, но сам полноэкранный показ в этой среде не подтвержден.

## Перед публикацией

Собрать проект заново, убедиться, что `docs/TEACHER_KEY.md` отсутствует в `dist`, затем разместить `dist` по подпути GitHub Pages. После публикации открыть фактический URL и проверить загрузку шрифтов, логотипа, трех дел и итоговой карты. Отдельно проверить статус workflow GitHub Pages.
