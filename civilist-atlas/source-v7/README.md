# ЦИВИЛИСТ V7. Рабочая ветка

Адрес проекта: `/sgua/civilist-atlas/`. Корень репозитория не меняется.

В ветке лежит готовый статический веб-комплект: `index.html`, `assets/` и `release.json`. Автономный экземпляр `CIVILIST_V7_working.html` передается отдельно вместе с архивом исходников; его SHA-256 указан в `release.json`. Для повторной сборки положите автономный файл в `downloads/CIVILIST_V7_working.html` и запустите `python3 source-v7/build_web.py`. Скрипт извлечет медиа и шрифты в `assets/`. Исходный учебный текст и логика находятся в автономном файле; `assets/app.js` является извлеченным модульным скриптом.

Полный преподавательский ключ не включен в эту публичную ветку.

Ветка сохраняет контрольную точку и не опубликована в GitHub Pages. Причина: проверен резервный браузерный режим, но текущая облачная среда отключает WebGL. Сведения о фактической проверке и оставшейся приемке приведены в `source-v7/QA_CHECKPOINT.md`.
