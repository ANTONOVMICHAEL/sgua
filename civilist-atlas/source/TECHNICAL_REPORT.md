# Технический отчет V5

08.11.2026. Node 24.22.1, Vite 8.3.6, Three.js 0.187.0. Два сборочных прохода: GitHub Pages и автономный single-file HTML. Build завершен без ошибок. Предупреждение о JS bundle >500 kB сохранено: библиотека Three включена локально для автономности. Offline HTML около 1,3 MB до сжатия.

## Реализовано

- Настоящие mesh, округлая геометрия, трубчатые элементы, отдельные крышки и шарниры, Canvas UV-текстуры; общий scene graph для GPU и резервного рендера.
- Основной WebGL2 renderer с PBR и тенями; Canvas-резерв с z-buffer и ограничением разрешения. Резерв не эквивалентен WebGL.
- ResizeObserver, ограниченный по времени RAF, остановка после перехода, отмена предыдущей анимации, освобождение геометрий, материалов и текстур при смене мира. Потеря WebGL переключает рендер на резерв.
- 22 кадра, 14 чтений документов, отдельные домашние условия, локальное сохранение, проверка корректности сохраненного номера, сброс, клавиатура и режим Аа.
- Все runtime-ресурсы локальные. Автономная CSP запрещает сеть, формы и внешнюю базу URL.

## Проверено

Production preview и автономный HTML исполнены в браузере. 10 контрактных/сборочных проверок пройдены: количество кадров, наличие вопросов, вывод только в конце, маркировка моделей, сохранение сумм и двух поставщиков, отсутствие внешних зависимостей HTML, CSP, встроенные шрифты и логотип, корректные entry-ресурсы по фиксированному base. Сырые результаты: qa/build-verification.json.

Все 22 состояния и документы пройдены в резервном режиме. Пять размеров layout viewport и мобильный режим измерены. Прогресс восстановлен после перезагрузки; повторные смены дел оставили один canvas. Подробности и ограничения: QA_REPORT.md.

## Ограничения

WebGL-контекст, PBR-качество, GPU FPS и GPU memory не проверены. file:// заблокирован политикой браузера. Fullscreen отклонен браузером. Проверка сети выполнена запретом CSP, не физическим отключением. Нет реального проектора, кликера и Safari/iOS. Нельзя объявлять полную аппаратную или художественную приемку.
