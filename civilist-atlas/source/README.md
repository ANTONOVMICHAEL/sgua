# Цивилист. Материальность права / V5

Интерактивный атлас для одного преподавателя. Тема: публично-правовые образования как субъекты гражданского права. Автор: Антонов М. А., кафедра гражданского права СГЮА. Семинар: 90 минут. Три дела: 7 + 6 + 9 кадров и общий итог.

Публичный адрес сохраняется: https://antonovmichael.github.io/sgua/civilist-atlas/

## Сборка

Требуется Node.js 22.12+ или 24 и npm.

```sh
npm ci
npm run dev
npm run build
```

`dist/` содержит GitHub Pages сборку с base `/sgua/civilist-atlas/`. `release/CIVILIST_atlas_offline.html` содержит автономный HTML с запрещенными сетевыми подключениями. ZIP включает этот файл и памятку. Во время занятия сервер, npm, CDN и база данных не требуются.

Исходники: main.js управляет состояниями и чтением; content.js сохраняет 22 кадра; homework.js содержит исходные условия; objects.js строит предметы; books.js управляет коллекцией; world.js строит три дела и итог; render.js реализует WebGL и резервную растеризацию той же геометрии. style.css создан заново.

Публикация: копировать `dist` в `civilist-atlas/`, сохраняя `source/`, и обновить автономные загрузки. Другие каталоги репозитория не изменять. GitHub Pages workflow публикует main. Для отката исходная версия: ac731b87f26ce961cc9642bfa0af0f67076411b5.

Отчеты: ART_DIRECTION.md, REFERENCE_AUDIT.md, STORYBOARD.md, LEGAL_AUDIT.md, QA_REPORT.md, TECHNICAL_REPORT.md, ACCEPTANCE.md. Основной WebGL-рендер в предоставленном Chrome не проверен: GL_RENDERER Disabled. Резервные снимки не подтверждают PBR-материалы и реальный FPS GPU. Прямой file:// запуск и физический проектор требуют отдельной проверки.

Полный преподавательский ключ и исходный методический архив не публикуются.
