# Цивилист. Государство на равных?

Интерактивный атлас для 90-минутного семинара второго курса. Три дела, 22 учебных кадра, 14 читаемых учебных документов, три полные фабулы. Основной режим использует Three.js и WebGL; при недоступности WebGL открывается графическое резервное представление с тем же содержанием и управлением.

## Разработка и сборка

```bash
pnpm install
pnpm dev
pnpm build
pnpm check
```

Папка `dist/` предназначена для `civilist-atlas/` GitHub Pages. Автономный файл создается в `release/CIVILIST_atlas_offline.html`. Он содержит код и локальные шрифты, без CDN.

Гарнитуры Onest, Literata и IBM Plex Mono распространяются по SIL Open Font License 1.1. Их уведомления и условия включены в `src/type/licenses/`.

Приватный преподавательский ключ не входит в исходники и выпуск.
