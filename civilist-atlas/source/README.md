# ЦИВИЛИСТ. Правовая лаборатория

Авторский цифровой атлас для очного конкурсного семинара «Государство на равных?». Автор: Антонов М. А., кафедра гражданского права СГЮА.

## Запуск

Требуются Node.js 22+ и npm. Из каталога исходного кода:

```bash
npm ci
npm run dev
```

Локальная страница открывается по адресу, напечатанному Vite. Для выпуска:

```bash
npm run build
```

`dist/` содержит статическую версию для GitHub Pages с базовым путем `/sgua/civilist-atlas/`. `release/CIVILIST_atlas_offline.html` является одним автономным файлом. `release/CIVILIST_atlas_offline.zip` включает его и памятку преподавателю. Автономный файл проверяй с отключенной сетью на целевом компьютере до занятия.

## Структура

- `src/books.js`: три физические книги из геометрии Three.js, процедурные обложки и блоки страниц.
- `src/world.js`: три дела и итоговая пространственная сцена; геометрия, материалы, освещение, ракурсы, анимации.
- `src/content.js`: учебные обстоятельства, вопросы, условные документы и правовые выводы.
- `src/main.js`: управление, локальное продолжение, полноэкранный режим, HTML-слой и резервная графика.
- `src/style.css`: проекционная композиция и адаптивная типографика.
- `LEGAL_AUDIT.md`, `STORYBOARD.md`, `REFERENCE_AUDIT.md`, `ART_DIRECTION.md`: юридическая, сценарная и художественная документация.

Внешних API, CDN, базы данных, регистрации и аналитики нет. WebGL создается только в браузере. При его отсутствии используются SVG/HTML; юридические тексты и клавиатурное управление доступны независимо от видеокарты. Состояние хранится локально в `localStorage` текущего браузера.

## Ограничения проверки

Публичная страница и резервный режим открыты в облачном Chrome, в котором WebGL системно отключен. Реальный 3D-рендер и частоту кадров там нельзя было измерить. Перед конкурсным занятием открой опубликованный адрес либо автономный файл на проекторном компьютере и убедись, что книги и здания вращаются и меняют ракурс; при отключенном WebGL будет явно обозначен резервный режим.
