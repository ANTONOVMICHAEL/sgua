# Визуальный и функциональный QA V5

Проверка 08.11.2026. Реальный облачный Chrome. Нативная область: 1363 × 936. Дополнительные размеры проверены как настоящие layout viewport внутри iframe, масштабированные для наблюдения на одном экране. Они не являются проверкой физического 4K-проектора.

## Выполнено

- Последовательно пройдены все 22 кадра и общий итог. Открыты и закрыты все 14 представлений документов. Счетчики, заголовки и отсутствие переполнения подтверждены DOM, qa/production-e2e.json.
- Проверены Space, стрелки, 1/2/3, Esc. Возврат с II/6 на II/5 убирает вывод. Перезагрузка предложила продолжить II/5 и восстановила его.
- Дополнительно выполнены 12 циклов открытия/закрытия документа и 12 смен дела. После них в DOM один canvas; это не измерение памяти GPU.
- 1366×768, 1440×900, 1920×1080, 2560×1440, 3840×2160: библиотека и плотные кадры I/5, II/5, III/7. scrollWidth и scrollHeight равны размерам страницы; у трех документов scrollHeight равен высоте поля чтения. Сырые измерения: qa/responsive-*.json.
- Мобильный layout 390×844: горизонтального скролла нет, вертикальная прокрутка разрешена. После снимка навигация переработана в отдельные строки для длинных названий.
- Финальная production-сборка открыта через статический preview. Автономный HTML исполнен через HTTP с CSP, запрещающей сеть; нет внешних script/src и stylesheet, document.fonts.status=loaded. Проверен III/7 и чтение документа. См. qa/offline-check.json.
- npm run build и 10 проверок npm test выполнены успешно. Проверены фиксированный base и наличие опубликованных entry-ресурсов.

## Три цикла визуальной редакции

1. По первым реальным снимкам заменена дефектная сортировка треугольников полноценным z-buffer, уменьшен масштаб коллекции, чтобы верх книг не выходил за кадр; исправлена тканевая фактура. Видимые разрывы и просвечивание граней устранены в резервном рендере.
2. После снимков документных сцен поле чтения вынесено в третью колонку; добавлены разные процессуальные листы, разведение юридических ролей в итогах и предметная интегральная сцена. Слишком длинный финал II переработан в явное сопоставление двух должников и отдельное чтение условий.
3. На 1366×768 выявлена лишняя прокрутка документа. Увеличена ширина чтения, убраны повторные служебные подписи, исправлены отступы. Повторные измерения всех трех плотных документов подтвердили полное размещение. Мобильные названия получили самостоятельные строки.

## Подтверждающие снимки

В qa/ включены только снимки с проверенным состоянием. Имена с 1366/1440/1920/2560/3840 обозначают размер layout viewport внутри видимого тестового стенда, не размер файла снимка. Снимки являются резервной Canvas-растеризацией реальной геометрии, не WebGL.

1366-iii-07-final.jpg и 1440-iii-07-reading-verified.jpg показывают текст документа и сохраненную предметную сцену. Остальные responsive JSON содержат проверку библиотеки и всех трех дел. Промежуточные снимки с прокруткой исключены из итогового набора.

## Не подтверждено

- Основной WebGL/PBR, реальные GPU-тени, hover-качество и FPS: Chrome сообщает GL_VENDOR/GL_RENDERER Disabled. Работу программного резерва нельзя считать такой проверкой.
- Прямой file:// запуск: протокол отклонен политикой облачного браузера. Обход не выполнялся.
- Физическое отключение сети не выполнялось; автономный файл проверен статически и под запретом сетевых подключений CSP.
- Fullscreen: F вызвал API, браузер отказал; показано уведомление. Физический проектор и кликер отсутствуют.
- Системный prefers-reduced-motion не переключался в ОС. Пользовательское отключение движения проверено; обработчик системной настройки проверен по коду.
- Видеозапись не выполнена. Отсутствие накопления GPU-ресурсов не измерено.

Публикация и последующая проверка отмечаются в отдельном протоколе выпуска. Полная художественная приемка основного WebGL-режима остается открытой.
