# Управление атласом

Открой ссылку. Выбери том I, II или III и веди обсуждение по кадрам. Главная кнопка справа внизу открывает следующий факт. Содержание само не перелистывается, предметная сцена продолжает движение.

| Действие | Команда |
| --- | --- |
| Следующий кадр | Page Down, стрелка вправо, пробел, нижняя правая кнопка |
| Предыдущий кадр | Page Up, стрелка влево, нижняя левая кнопка |
| Выбрать дело | 1, 2, 3 или номера вверху |
| Открыть документ | «Читать документ» или предметный документ в сцене |
| Закрыть документ | Esc или «К обсуждению» |
| Пауза движения | M или «Пауза» вверху |
| Полный экран | F |

Кнопка «Полное условие» доступна в каждом кадре. Пройденные шаги можно открыть повторно. Атлас хранит место в каждом деле на устройстве, а после перезагрузки предлагает продолжить. Сброс для новой группы находится в справке «?».

Документы и судебное решение являются учебными моделями. Для демонстрации без интернета используй автономный HTML.
