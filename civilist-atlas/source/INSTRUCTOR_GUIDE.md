# Цивилист V5. Памятка преподавателю

Открой сайт или автономный HTML. Студенты заранее решают три казуса. На занятии работает один экран; регистрация, телефоны и сбор онлайн-ответов не нужны.

| Команда | Действие |
| --- | --- |
| 1, 2, 3 | Открыть дело |
| Пробел, → | Следующий факт; затем осознанный переход к выводу |
| ← | Назад |
| Esc | Закрыть документ; повторно вернуться в атлас |
| F | Полный экран, если разрешен браузером |
| R | Повторить движение |
| Аа | Увеличить текст |
| Движение вкл/выкл | Переключить анимацию |

Документ открывается кнопкой или выбором физического листа. Полное условие доступно отдельно. После перезагрузки библиотека предлагает продолжить с последнего этапа. Сброс удаляет только локальный прогресс. Сцена останавливается для обсуждения.

Тайминг: 0-7 мин входная диагностика; 7-17 нормы; 17-31 дело I; 31-48 дело II; 48-78 дело III; 78-84 систематизация; 84-90 итоговая письменная фиксация. Перед командным обсуждением 45-60 секунд на личную позицию. Четыре команды исследуют субъектов, компетенцию, ответственность и контраргументы; роли меняются между делами. Оценивание остается очным.

Автономный запуск: распакуй ZIP и открой CIVILIST_atlas_offline.html двойным щелчком в современном браузере. Все зависимости включены; политика CSP запрещает сетевые подключения. Непосредственный file:// запуск на компьютере аудитории в данной среде не проверен. При недоступности WebGL автоматически включается резервная графика. Проверь файл на проекторном компьютере до занятия.

Все факты и документы условные. Полный закрытый ключ в комплект не включен.
