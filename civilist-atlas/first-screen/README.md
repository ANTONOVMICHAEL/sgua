# ЦИВИЛИСТ — первый экран

Проверочный первый экран правовой лаборатории. Одна сцена, один предмет, один режим крупного рассмотрения. Остальные разделы сайта здесь не создаются.

## Воспроизведение

Открой `index.html` через локальный HTTP-сервер, например `python -m http.server 8000`, затем перейди на `http://localhost:8000/`. Нужен браузер с WebGL 2. Для пересборки JavaScript: `npm ci && npm run build`.

## Что происходит в трех измерениях

- `asset/binder_notebook.glb` содержит сетку реального предмета, UV-координаты и PBR-карты материала. Модель можно осмотреть вращением мышью или пальцем.
- Дополнительный лист создается как сетка 28 × 32 сегмента. При нажатии «Рассмотреть объект» меняются координаты его вершин, положение и изгиб; лист отдельно от переплета отбрасывает тень.
- Перспективная камера и источник света движутся в сцене. WebGL заново рассчитывает проекцию, освещение PBR-материала и карту теней на каждом кадре.
- Большая типографика остается HTML-текстом, поэтому она четкая и доступна как текст. Трехмерная сцена не подменена видеороликом, фотографией или CSS-трансформацией картинки.

## Исходный материал и лицензии

- 3D-модель **Binder Notebook**, автор DaDrood, [Poly Haven](https://polyhaven.com/a/binder_notebook), лицензия CC0. Включена оптимизированная версия с картами 1K. Автор и источник указаны добровольно.
- Three.js, лицензия MIT, [репозиторий](https://github.com/mrdoob/three.js). Собранный модуль включен в `app.bundle.js`.
- Шрифты Unbounded, Manrope и IBM Plex Mono поставляются через Fontsource на условиях OFL; см. `node_modules` после `npm ci` и соответствующие репозитории шрифтов.

Исходный код страницы: `index.html`, `style.css`, `app.js`. Скомпилированный `app.bundle.js` нужен для автономной работы без CDN. GLB и шрифты хранятся рядом со страницей; внешние запросы для отображения не требуются.
