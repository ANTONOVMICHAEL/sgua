# Ведомости · журнал преподавателя

Личный журнал Михаила Антонова. Рабочая публикация: https://antonovmichael.github.io/sgua/zhurnal-2026/

## Возможности

- Светлый кабинет с верхней навигацией на компьютере и нижней панелью на телефоне; локальная Inter, белые поверхности, графитовый текст и бирюзовый акцент.
- Карусель групп: свайп/прокрутка с фиксацией на телефоне, перетаскивание мышью, стрелки, клавиши ←/→/Home/End.
- Рейтинг активности: блок лидера, тройка лучших, график по занятиям, сводные показатели, поиск, сортировка, CSV и настраиваемые баллы.
- Четыре группы и 89 студентов из исходных ведомостей; состав можно редактировать и архивировать.
- Занятия по датам и парам, посещаемость П / Н / О / У, массовая отметка оставшихся студентов.
- Ответ на каждой паре: «+» без оценки или оценка 2–5, отдельный комментарий.
- Задолженности с темой, видом работы, сроком и комментарием; погашение с записью результата и повторное открытие.
- Карточка студента с историей посещаемости, ответов и задолженностей; средняя оценка считает только числовые оценки.
- Сводная ведомость за все занятия и CSV для Excel. Резервная копия JSON переносит весь журнал, включая новые записи.

## Хранение и совместимость

Сайт работает непосредственно на GitHub Pages. Все рабочие записи хранятся в браузере в ключе `sgua-journal-v1`. Предыдущие записи с тем же ключом подхватываются автоматически; отсутствующие поля ответов и задолженностей добавляются при чтении. Новая версия не обнуляет состав и отметки. Данные на разных устройствах не синхронизируются автоматически.

Загрузка копии проверяет связи записей до замены данных. Состояние перед импортом сохраняется в `sgua-journal-before-import`; его можно восстановить в разделе «Данные». Скрытые занятия сохраняются и восстанавливаются в этом же разделе. При ошибке записи в браузер приложение оставляет предыдущее состояние.

В приложении нет автоматического выставления оценок или задолженностей: решения и отметки вводит преподаватель. Публичная сборка содержит исходные имена студентов; история посещаемости, оценки и задолженности на сервер GitHub не отправляются. Перед изменением публичного состава следует проверить, какие данные предполагается публиковать.

## Разработка

Требуется Node.js 22.13+ (для тестов со встроенной поддержкой TypeScript) и npm.

```sh
npm install
npm run dev
npm run test
npx tsc --noEmit
npm run build
```

Содержимое `dist/` публикуется в `zhurnal-2026/` публичного репозитория `ANTONOVMICHAEL/sgua`. Параметр `base: './'` сохраняет работу во вложенном пути Pages. Исходники находятся в `zhurnal-2026/source/`; внутренний каталог `source/dist/` не публикуется.

## Визуальная система

Новая композиция использует светлый фон, белые рабочие поверхности, глубокий бирюзовый текст и контрастный акцент. Весь интерфейс — в `studio.css`: заголовки, единая лента групп, ведомость, рейтинг, формы и адаптивные состояния. Предыдущие CSS-файлы не подключаются.

На компьютере навигация находится сверху. На телефоне доступны нижняя панель разделов и свайп по ленте групп. На пустой группе показывается обложка с предметным рендером книги и реальные имена из состава. После создания занятия основное место занимает рабочая ведомость. Переход между разделами возвращает страницу к заголовку. На узком экране строки перестраиваются для отметок пальцем.

Рейтинг содержит выделенный результат лидера, тройку лучших, линейный график реальной посещаемости и ответов, показатели и таблицу. На графике подписаны даты и пары; при единственном занятии показываются точки, без выдуманного тренда. Рейтинг и журнал используют прежние данные и правила расчета.

Локальная вариативная Inter поддерживает кириллицу. Внешних запросов к сервисам шрифтов нет; лицензия SIL Open Font License — `fonts/Inter-OFL.txt`. Источник шрифта, сведения о графике и точный запрос на ее создание описаны в `DESIGN.md`. Официальный юбилейный SVG СГЮА сохранен.

## Рейтинг активности

Рейтинг — накопительный рабочий показатель; он не заменяет выставленные преподавателем оценки. Настройки сохраняются в том же JSON журнала. Базовый расчет:

- Посещение «П» или «О»: +1 балл.
- Ответ «+»: +2 балла; оценки 2 / 3 / 4 / 5: 0 / 1 / 2 / 3 балла соответственно.
- Открытый долг: −2 балла. Погашение снимает вычет.
- Незаполненные отметки, «Н» и «У» не создают вычеты. Для процента посещаемости учитываются только заполненные отметки, «У» исключается из знаменателя.
- Будущие и скрытые занятия исключены. За посещение и за ответ можно получить баллы независимо.
- Равные баллы дают одинаковое место. Студенты без записей не ранжируются. При сравнении всех групп следует учитывать, что баллы накопительные и число занятий может различаться.

Вес каждого компонента меняется от 0 до 20 в разделе «Настроить баллы». Настройки входят в резервную копию. Дата последнего сохранения `savedAt` записывается после успешной операции; данные фиксируются синхронно в хранилище браузера до обновления интерфейса. Все прежние занятия сохраняются при обновлении приложения.

## Проверки

`storage.test.mjs` проверяет миграцию прежних копий без потери отметок, независимость ответов от посещаемости, погашение и повторное открытие долга, перенос данных, отказ от поврежденной копии, восстановление состояния перед импортом, ошибку хранилища, уникальность пары, скрытие/восстановление занятия и экранирование CSV.

`rating.test.mjs` проверяет баллы, равные места, отсутствие ранга без данных, уважительные пропуски, снятие вычета после погашения, исключение будущих/скрытых занятий и сохранение настроек вместе со старыми занятиями.
